## 任务提示词

以下为本题完整的 User Prompt 原文，两次执行必须使用完全相同的文本。

法务要求上线前确认所有第三方依赖的许可证，现在还得人工一个个翻 pom 文件。请从零实现一个 Gradle 插件来做这件事，仓库目前只有一个空的 Gradle 插件工程（build.gradle 只声明了 java-gradle-plugin 与 JUnit 5）。要求：1) 依赖与许可证采集：解析项目运行时依赖（含传递依赖），从本地缓存或依赖元数据中提取每个构件的许可证信息；无法识别许可证的构件必须显式标记为「未知」，不得直接跳过；2) 规则配置：插件提供一段 DSL，支持白名单（允许的许可证）、黑名单（禁止的许可证）以及按构件坐标覆盖规则；3) 报告：生成人类可读的文本报告与机器可读的 JSON 报告，按构件列出名称、版本、许可证、判定结果与命中的规则；4) 门禁：出现黑名单命中，或存在未显式允许的未知许可证时，任务失败并返回非零退出码；同时提供配置项可放宽为仅告警；5) 缓存与增量：任务需正确声明输入与输出，输入未变时重复执行应判定为 up-to-date；6) 测试：用 Gradle TestKit 编写集成测试，覆盖合规通过、黑名单命中导致失败、未知许可证告警、坐标覆盖规则四种场景；测试使用本地构造的假仓库数据，不依赖联网下载；7) `./gradlew test` 一条命令跑通；8) README 说明规则语义与已知限制。

## 提交要求

1. 在本仓库中完成提示词要求的全部内容。
2. ./gradlew test 必须通过。
3. 完成后在所属分支（A 或 B）上提交，产物快照的父提交必须是初始环境快照。
